# Sicherheit

Bitte keine Schülerdaten, Fotos, Zugangsdaten oder ausnutzbaren Sicherheitsdetails
in öffentliche Issues einstellen. Sicherheitsprobleme vertraulich an
marc.schulz@bbs-einbeck.de melden; Version, betroffene Funktion und eine synthetische
Reproduktion genügen. Keine garantierte Reaktionszeit oder formale Audit-Zertifizierung.

GitHub Pages liefert ausschließlich Projektinformationen und eine statische DEMO.
Dort gibt es keine Anmeldung, Fach-API oder dauerhafte Klassen-/Fotospeicherung.
Lokale Testbilder bleiben im Browser. GitHub betreibt das Hosting; die Demo sendet
keine eigene Nutzungsstatistik an den Schulserver.

Die Serverversion prüft IServ-Identität, Teacher-Rolle und Klassenrechte auf dem Server,
verwendet CSRF-Schutz, revisionsgeprüfte Speicherung, Bildneukodierung und private Ablage.
Der öffentliche Stand enthält nur Platzhalterkonfiguration und synthetische Testdaten.
Betriebliche Freigaben, Aufbewahrungsfristen, Backup/Wiederherstellung, Vertretung und
Monitoring müssen je Installation festgelegt und geprüft werden.
